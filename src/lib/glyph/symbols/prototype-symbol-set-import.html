Importing a Symbol Set Prototype

A throwaway demo for issue #38. Nothing here ships; it exists to settle one argument before the real code is written.

The question. A Symbol Set is a drawing an author exports from their design tool: one file holding many little pictures on a grid, each named. The tool cuts that file into individual symbols, works out which of them it already knows (an A button, a bumper) and which are new, and asks the importer to check the result before accepting it. Then — later — the author re-exports the file and presses refresh.

What should refresh do? The drawing has moved on: art changed, names appeared or vanished, colours were corrected. Meanwhile the importer has renamed things and picked colours, and glyphs in the project are already using these symbols. Which side wins? The answer here is that the set is exactly what the file draws — nothing is retained behind the drawing's back — and the tool's job when a symbol a glyph was using disappears is to say so, by name. Press the buttons and see whether the rules below feel right.
